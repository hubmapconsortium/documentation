## HuBMAP Metadata by Dataset Type

A list of available dataset types (data types from multiple supported assays), with a link [<img src="info3.png" width="14">](enhancedsrs "Click for assay description") to the valid metadata attributes for each dataset type. The linked assay metadata pages list all attributes, as they have occurred, across any versions of the metadata specification for the given dataset type with the most current, valid set of attributes listed first on the page. The directory schema for each dataset type is also linked in the description column.

| Dataset Type | Description |
|--------------|-------------|
| [4i](4i) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/4i/current/#directory-schemas "Click for directory schema") | 4i, or Iterative Indirect Immunofluorescence Imaging, is a high-resolution technique for imaging proteins within cells and tissues. |
| [10X Multiome](10x-multiome) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/10x-multiome/current/#directory-schemas "Click for directory schema") | 10X Multiome is a multimodal single-cell sequencing technology that simultaneously captures both gene expression (RNA-seq) and chromatin accessibility (ATAC-seq) from the same individual nucleus. Both RNA molecules and open-chromatin DNA fragments are labeled with a unique per-nucleus barcode using the 10x Genomics Chromium platform, allowing paired readouts to be linked to the same cell of origin. |
| [Autofluorescence (AF)](af) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/af "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/af/current/#directory-schemas "Click for directory schema") | Exploits endogenous fluorescence in biological tissue to capture an image. The image can be used to integrate other images from multiple modalities and align tissues within a 3D experiment. |
| [ATACseq](atacseq) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/atacseq "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/atacseq/current/#directory-schemas "Click for directory schema") | Assay for Transposase-Accessible Chromatin using sequencing (ATACseq) identifies accessible DNA regions, probing open chromatin with hyperactive mutant Tn5 Transposase that inserts sequencing adapters into open regions of the genome. |
| [CODEX](codex) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/codex "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/codex/current/#directory-schemas "Click for directory schema") | Co-detection by indexing (CODEX) is a strategy for generating highly multiplexed images of fluorescently-labeled antigens. |
| [COMET](comet) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/comet/current/#directory-schemas "Click for directory schema") | COMET is a technique used to measure DNA damage in individual cells. The name comes from the shape that damaged DNA fragments form when they migrate out of a cell's nucleus under an electric field, resembling a comet with a head and a tail. This assay is widely used in genetics research to study DNA damage from factors like radiation, chemicals, and environmental exposure. |
| [CosMx Proteomics](cosmx-proteomics) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/cosmx-proteomics/current/#directory-schemas "Click for directory schema") | CosMx Proteomics is a technology that enables the high-resolution, spatial analysis of proteins within their native tissue environment. It is part of the CosMx Spatial Molecular Imager (SMI) platform, which provides single-cell and subcellular resolution to map protein expression, cell states, and cell-cell interactions in FFPE and fresh frozen tissue samples. |
| [CosMx Transcriptomics](cosmx-transcriptomics) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/cosmx-transcriptomics/current/#directory-schemas "Click for directory schema") | Dataset generated from performing the CosMx Transcriptomics assay. |
| [DESI](desi) [<img src="info3.png" width="14">](https://pmc.ncbi.nlm.nih.gov/articles/PMC6053038/ "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/desi/current/#directory-schemas "Click for directory schema") | Desorption Electrospray Ionization (DESI), an ambient ionization technique that can be coupled to mass spectrometry (MS) for chemical analysis of samples at atmospheric conditions. |
| [DNA Methylation](dna-methylation) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/dna-methylation/current/#directory-schemas "Click for directory schema") | DNA methylation is a critical, reversible epigenetic mechanism in biomedical research involving the addition of a methyl group to DNA (usually cytosine in CpG islands), altering gene expression without changing the underlying sequence. |
| [Enhanced SRS](enhanced-srs) [<img src="info3.png" width="14">](https://www.nature.com/articles/s41467-019-13230-1 "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/enhanced-srs/current/#directory-schemas "Click for directory schema") | Refers to improvements made to Stimulated Raman Scattering (SRS), a technique used in microscopy and spectroscopy for chemical imaging and analysis. These enhancements aim to improve sensitivity, spatial resolution, and other capabilities of SRS. |
| [GeoMx](geomx-ngs) [<img src="info3.png" width="14">](https://nanostring.com/products/geomx-digital-spatial-profiler/spatial-multiomics-enabled-with-geomx-dsp/ "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/geomx-ngs/current/#directory-schemas "Click for directory schema") | A platform for spatial biology that analyzes RNA and protein expression within tissue sections which allows for non-destructive, in situ profiling of gene expression and protein levels from specific regions of interest (ROIs) within a tissue. |
| [HiFi Slide](hifi-slide) [<img src="info3.png" width="14">](https://www.researchgate.net/publication/370676672_HiFi-Slide_spatial_RNA-Sequencing_v2 "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/hifi-slide/current/#directory-schemas "Click for directory schema") | High-Fidelity Spatial Transcriptomic Slide (HiFi-Slide) sequencing, a super-resolution spatial transcriptomics sequencing technology, captures and spatially resolves genome-wide RNA expression in a submicron resolution for fresh-frozen tissue. |
| [Histology](histology) [<img src="info3.png" width="14">](https://en.wikipedia.org/wiki/Histology "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/histology/current/#directory-schemas "Click for directory schema") | The microscopic study of tissue composition and structure, often referred to as microscopic anatomy. It involves examining tissue samples, typically after they've been sectioned, stained, and placed under a microscope. |
| [iCLAP](iclap) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/iclap/current/#directory-schemas "Click for directory schema") | iCLAP (individual-nucleotide resolution UV-crosslinking and affinity purification) is a specialized, high-stringency technique designed to map the specific RNA binding sites of RNA-binding proteins (RBPs) at the single-nucleotide level. |
| [Illumina Spatial ver0](illumina-spatial-ver0) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/illumina-spatial-ver0/current/#directory-schemas "Click for directory schema") | Illumina Spatial ver0 is a high-resolution, sequencing-based spatial transcriptomics solution that maps gene expression within intact tissue samples, preserving spatial context. It combines broad, unbiased whole-transcriptome profiling with cellular-level resolution (1-µm features) over large areas () using standard Illumina NextSeq and NovaSeq. |
| [IMC 2D](imc-2d) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/imc-2d "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/imc-2d/current/#directory-schemas "Click for directory schema") | Combines standard immunohistochemistry with CyTOF mass cytometry to resolve the cellular localization of up to 40 proteins in a tissue sample. |
| [IMC 3D](imc3d) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/imc3d "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/imc3d/current/#directory-schemas "Click for directory schema") | |
| [LC-MS](lcms) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/lcms "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/lcms/current/#directory-schemas "Click for directory schema") | Coupling of liquid chromatography (LC) to mass spectrometry (MS). |
| [Light Sheet](lightsheet) [<img src="info3.png" width="14">](https://en.wikipedia.org/wiki/Light_sheet_fluorescence_microscopy "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/lightsheet/current/#directory-schemas "Click for directory schema") | A fluorescence imaging technique that uses a thin sheet of laser light to illuminate a sample, allowing for high-resolution, 3D imaging with reduced photobleaching and phototoxicity; particularly useful for imaging large, thick, or delicate biological samples, like developing embryos or organoids. |
| [MACSima](macsima) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/macsima/current/#directory-schemas "Click for directory schema") | MACSima is a fully automated, high-content spatial biology system designed for ultra-high-plex, cyclic immunofluorescence imaging. It enables researchers to map hundreds of protein markers, and some RNAs, on a single tissue sample using [MICS technology (MACSima Imaging Cyclic Staining)](https://www.nature.com/articles/s41598-022-05841-4), combining deep phenotyping with spatial context. |
| [MALDI-IMS](maldi) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/maldi-ims "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/maldi/current/#directory-schemas "Click for directory schema") | Matrix-assisted laser desorption/ionization (MALDI) imaging mass spectrometry (IMS) combines the sensitivity and molecular specificity of MS with the spatial fidelity of classical microscopy. |
| [MIBI](mibi) [<img src="info3.png" width="14">](https://www.researchgate.net/figure/Multiplexed-ion-beam-imaging-workflow-for-high-resolution-spatial-proteomics-Here_fig1_349770840 "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/mibi/current/#directory-schemas "Click for directory schema") | Preserved tissue sections, mounted on conductive substrates are incubated with unique isotopic transition metal-tagged antibody reporters. An oxygen primary ion beam rasters the sample surface, ejecting and ionizing the isotope reporters. Their masses are subsequently measured via a mass analyzer. |
| [MERFISH](merfish) [<img src="info3.png" width="14">](https://pubmed.ncbi.nlm.nih.gov/27241748/ "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/merfish/current/#directory-schemas "Click for directory schema") | A spatial transcriptomics technology that allows for the simultaneous imaging of hundreds to thousands of RNA species within single cells, providing both copy number and spatial distribution information. |
| [MUSIC](music) [<img src="info3.png" width="14">](https://www.nature.com/articles/s41586-024-07239-w "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/music/current/#directory-schemas "Click for directory schema") | A sequencing assay that allows profiling of gene expression, co-complexed DNA sequences, and RNA-chromatin interactions from the same single-cell nucleus. Both RNA and fragmented DNA within a nucleus are labelled with a unique cell barcode, enabling identification and matching of RNA and DNA sequences. |
| [Paired Tag](paired-tag) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/paired-tag/current/#directory-schemas "Click for directory schema") | Paired-Tag (parallel analysis of individual cells for RNA expression and DNA from targeted tagmentation by sequencing) is a high-throughput, single-cell multiomics method that simultaneously maps histone modifications and gene expression (transcriptome) in the same single cell. |
| [Pixel-seqV2](pixel-seqv2) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/pixel-seqv2/current/#directory-schemas "Click for directory schema") | Pixel-seqV2 is a spatial transcriptomics method that utilizes polony gels to capture and sequence RNA, proteins or other molecules in tissues with high resolution. These polony gels are arrays of micron-scale DNA clusters, each containing a unique barcode, allowing for the mapping of molecules within their original spatial context in a tissue, thereby allowing researchers to study the spatial organization of cells and their gene expression profiles within tissues.|
| [Raman-Imaging](raman-imaging) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/raman-imaging/current/#directory-schemas "Click for directory schema") | Raman Imaging is a non-invasive technique that maps the unique chemical fingerprint of biological samples (cells, tissues) by capturing Raman scattering (light interacting with molecular vibrations) at each pixel, creating detailed molecular maps showing the distribution of proteins, lipids, DNA, and water. |
| [RNAseq](rnaseq) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/rnaseq "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/rnaseq/current/#directory-schemas "Click for directory schema") |[<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/rnaseq/current/#directory-schemas "Click for directory schema")  While bulk RNAseq elucidates the average gene expression profile in cells comprising a tissue sample, single-cell RNAseq employs per-cell and per-molecule barcoding to enable single-cell resolution of the gene expression profile. |
| [RNAseq with Probes](rnaseq-with-probes) [<img src="info3.png" width="14">](https://pmc.ncbi.nlm.nih.gov/articles/PMC5717752/# "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/rnaseq-with-probes/current/#directory-schemas "Click for directory schema") | Uses probes to capture and enrich specific regions of the RNA for targeted sequencing, allowing for in-depth analysis of those regions.|
| [SHG](second-harmonic-generation) [<img src="info3.png" width="14">](https://en.wikipedia.org/wiki/Second-harmonic_imaging_microscopy "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/second-harmonic-generation/current/#directory-schemas "Click for directory schema") | Single-cycle Fluorescence Microscopy (SFM). A technique that utilizes the nonlinear optical phenomenon of SHG to image biological tissues and structures, particularly those containing collagen.|
| [SeqFISH](seqfish) [<img src="info3.png" width="14">](https://docs.hubmapconsortium.org/assays/seqfish "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/seqfish/current/#directory-schemas "Click for directory schema") | SeqFISH technology allows in situ imaging of multiple mRNAs using barcoding and fluorophore-labelled barcode readout-probes. _The consortium is no longer accepting data of this type_.|
| [SIMS](sims) [<img src="info3.png" width="14">](https://www.frontiersin.org/journals/chemistry/articles/10.3389/fchem.2023.1237408/full "Click for assay description") | Secondary-ion mass spectrometry (SIMS) is a technique used to analyze the composition of solid surfaces and thin films by sputtering the surface of the specimen.|
| [Slide-seq](slideseq) [<img src="info3.png" width="14">](https://www.nature.com/articles/s41587-020-0739-1 "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/slideseq/current/#directory-schemas "Click for directory schema") | Provides a scalable method for obtaining spatially resolved gene expression data at resolutions comparable to the sizes of individual cells.|
| [SnareSeq2](snareseq2) [<img src="info3.png" width="14">](https://www.nature.com/articles/s41596-021-00507-3 "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/snareseq2/current/#directory-schemas "Click for directory schema") | This method uses tagmentation within permeabilized and fixed single-nucleus isolates to capture accessible chromatin (AC) regions, followed by the capture and reverse transcription of RNA transcripts.|
| [STARmap](starmap) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/starmap/current/#directory-schemas "Click for directory schema") | STARmap (Spatially-resolved Transcript Amplicon Readout Mapping) is a biomedical technology that enables the 3D mapping of gene expression within intact tissues at single-cell resolution. It combines hydrogel-tissue chemistry and in situ DNA sequencing to preserve a cell's location and identify which genes are active in that specific spatial context. [STARmap directory schema](https://hubmapconsortium.github.io/ingest-validation-tools/starmap/current/). |
| [Thick Section Multiphoton MxIF](thick-section-multiphoton-mxif) [<img src="info3.png" width="14">](https://pmc.ncbi.nlm.nih.gov/articles/PMC9959383/# "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/thick-section-multiphoton-mxif/current/#directory-schemas "Click for directory schema") | One version of MXIF (multiplexed fluorescence microscopy), an imaging platform whereby a large number of cellular and histological markers can be investigated on a single tissue section.|
| [Visium No Probes](visium-no-probes) [<img src="info3.png" width="14">](https://ostr.ccr.cancer.gov/emerging-technologies/spatial-biology/visium/ "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/visium-no-probes/current/#directory-schemas "Click for directory schema") | A spatial transcriptomics solution that allows researchers to analyze gene expression patterns within the spatial context of a tissue. An in situ method that captures RNA transcripts within the tissue and then sequences them. |
| [Visium with Probes](visium-with-probes) [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/visium-with-probes/current/#directory-schemas "Click for directory schema") | Offers spatially resolved transcriptomics through the 10X Genomics Visium CytAssist, which combines histology with probe-based transcriptomics in a spatial context. |
| [WGS](wgs) [<img src="info3.png" width="14">](https://en.wikipedia.org/wiki/Whole_genome_sequencing "Click for assay description") [<img src="dir-icon3.png" width="14">](https://hubmapconsortium.github.io/ingest-validation-tools/wgs/#directory-schemas "Click for directory schema") | The process of determining the entire DNA sequence of an organism's genome at a single time. This entails sequencing all of an organism's chromosomal and mitochondrial DNA. _The consortium is no longer accepting data of this type_. |
